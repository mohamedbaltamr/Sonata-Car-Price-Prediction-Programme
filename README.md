## 🚀 How to Use

Follow these steps to get started with the Sonata Price Predictor:

1. **Run the Program**
   - Execute the main script:
     ```bash
     python main.py
     ```
   - Wait for the model to process the training data and initialize. 
   - *Tip:* You can freely modify or expand the dataset within the code to improve accuracy.

2. **Predict Your Sonata's Price**
   - The program will prompt you with interactive questions about your car's specifications (e.g., Year, Mileage, Condition).
   - Input the details to receive an **instant price prediction** based on the trained model.

3. **Experiment**
   - You can rerun the program as many times as you like to test different configurations and see how various factors affect the market value.
